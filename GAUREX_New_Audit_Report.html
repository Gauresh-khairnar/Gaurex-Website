Technical Security Implementation

  • Server-Side Validation: Form input processed via Next.js Server Action (submitContactInquiry) with regex validation on emails and minimum length constraints on names and company fields.
  • Honeypot Anti-Spam Gate: Hidden form input catches automated bot scrapers and silently discards spam without annoying human users with CAPTCHAs.
  • Security Headers: Configured in next.config.ts:
    • X-Frame-Options: DENY (Blocks clickjacking)
    • X-Content-Type-Options: nosniff (Blocks MIME sniffing)
    • X-XSS-Protection: 1; mode=block
    • Referrer-Policy: strict-origin-when-cross-origin
